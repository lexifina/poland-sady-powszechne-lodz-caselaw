# Sąd Rejonowy w Ciechanowie, Wyrok, 2021-08-12, I C 235/18

## Teza

I powództwo oddala;
II zasądza od powódki M.K. na rzecz pozwanej U.M. kwotę 4106,30 zł ( cztery tysiące sto sześć złotych trzydzieści groszy ) tytułem zwrotu kosztów procesu, w tym 3600,00 zł ( trzy tysiące sześćset złotych ) tytułem zwrotu kosztów zastępstwa procesowego;
III nakazuje Skarbowi Państwa wypłacić powódce M.K. kwotę 501,10 zł ( pięćset jeden złotych dziesięć groszy ) tytułem zwrotu niewykorzystanej części zaliczki zaksięgowanej pod pozycją U11-11717980 KU 500000941988 PH 1002678423;
IV nakazuje Skarbowi Państwa wypłacić pozwanej U.M. kwotę 493,70 zł ( czterysta dziewięćdziesiąt trzy złote siedemdziesiąt groszy ) tytułem zwrotu niewykorzystanej części zaliczki zaksięgowanej pod pozycją U11-11717980 KU 500001435484 PH 1003371430.
