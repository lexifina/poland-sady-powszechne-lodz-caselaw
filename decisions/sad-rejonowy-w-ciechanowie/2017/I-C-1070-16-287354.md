# Sąd Rejonowy w Ciechanowie, Wyrok, 2017-05-04, I C 1070/16

## Teza

I umarza postępowanie co do kwoty 10819,70 zł ( dziesięć tysięcy osiemset dziewiętnaście złotych siedemdziesiąt groszy );
II zasądza od pozwanego ... w C. na rzecz powódki A.S. kwotę 339,69 zł ( trzysta trzydzieści dziewięć złotych sześćdziesiąt dziewięć groszy );
III zasądza od pozwanego ... w C. na rzecz powódki A.S. kwotę 5358,00 zł ( pięć tysięcy trzysta pięćdziesiąt osiem złotych ) tytułem zwrotu kosztów procesu, w tym 4817,00 zł ( cztery tysiące osiemset siedemnaście złotych ) tytułem zwrotu kosztów zastępstwa procesowego;
IV umarza postępowanie co do kwoty 10119,62 zł ( dziesięć tysięcy sto dziewiętnaście złotych sześćdziesiąt dwa grosze );
V zasądza od pozwanego ... w C. na rzecz powódki A.S. kwotę 655,03 zł ( sześćset pięćdziesiąt pięć złotych trzy grosze );
VI zasądza od pozwanego ... w C. na rzecz powódki A.S. kwotę 5323,00 zł ( pięć tysięcy trzysta dwadzieścia trzy złote ) tytułem zwrotu kosztów procesu, w tym 4817,00 zł  ( cztery tysiące osiemset siedemnaście złotych ) tytułem zwrotu kosztów zastępstwa procesowego;
VII umarza postępowanie co do kwoty 11000,07 zł ( jedenaście tysięcy złotych siedem groszy );
VIII zasądza od pozwanego ... w C. na rzecz powódki A.S. kwotę 543,63 zł ( pięćset czterdzieści trzy złote sześćdziesiąt trzy grosze );
IX zasądza od pozwanego ... w C. na rzecz powódki A.S. kwotę 5368,00 zł ( pięć tysięcy trzysta sześćdziesiąt osiem złotych ) tytułem zwrotu kosztów procesu, w tym 4817,00 zł ( cztery tysiące osiemset siedemnaście złotych ) tytułem zwrotu kosztów zastępstwa procesowego.
