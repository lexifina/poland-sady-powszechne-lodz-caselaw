# Sąd Rejonowy w Ciechanowie, Wyrok, 2017-12-14, I C 1309/17

## Teza

I zasądza od pozwanego S.S.W. w C. na rzecz powoda B.C. P. Spółka z ograniczoną odpowiedzialnością  w W. kwotę 30529,59 zł ( trzydzieści tysięcy pięćset dwadzieścia dziewięć złotych pięćdziesiąt dziewięć groszy ) z tym, że:
- kwotę 945,73 zł ( dziewięćset czterdzieści pięć złotych siedemdziesiąt trzy grosze ) z ustawowymi odsetkami za opóźnienie od dnia 09 lutego 2017  r. do dnia zapłaty;
- kwotę 7386,12 zł ( siedem tysięcy trzysta osiemdziesiąt sześć złotych dwanaście groszy ) z ustawowymi odsetkami za opóźnienie od dnia 23 lutego 2017  r. do dnia zapłaty;
- kwotę 4428,58 zł ( cztery tysiące czterysta dwadzieścia osiem złotych pięćdziesiąt osiem groszy ) z ustawowymi odsetkami za opóźnienie od dnia 23 lutego 2017  r. do dnia zapłaty;
- kwotę 123,00 zł ( sto dwadzieścia trzy złote ) z ustawowymi odsetkami za opóźnienie od dnia 07 marca 2017  r. do dnia zapłaty;
- kwotę 2352,90 zł ( dwa tysiące trzysta pięćdziesiąt dwa złote dziewięćdziesiąt groszy ) z ustawowymi odsetkami za opóźnienie od dnia 17 marca 2017  r. do dnia zapłaty;
- kwotę 2019,60 zł ( dwa tysiące dziewiętnaście złotych sześćdziesiąt groszy ) z ustawowymi odsetkami za opóźnienie od dnia 17 marca 2017  r. do dnia zapłaty;
- kwotę 3781,24 zł ( trzy tysiące siedemset osiemdziesiąt jeden złotych dwadzieścia cztery grosze ) z ustawowymi odsetkami za opóźnienie od dnia 30 marca 2017  r. do dnia zapłaty;
- kwotę 4107,22 zł ( cztery tysiące sto siedem złotych dwadzieścia dwa grosze ) z ustawowymi odsetkami za opóźnienie od dnia 08 kwietnia 2017  r. do dnia zapłaty;
- kwotę 123,00 zł ( sto dwadzieścia trzy złote ) z ustawowymi odsetkami za opóźnienie od dnia 11 kwietnia 2017  r. do dnia zapłaty;
- kwotę 3586,31 zł ( trzy tysiące pięćset osiemdziesiąt sześć złotych trzydzieści jeden groszy ) z ustawowymi odsetkami za opóźnienie od dnia 13 kwietnia 2017  r. do dnia zapłaty;
- kwotę 1552,89 zł ( jeden tysiąc pięćset pięćdziesiąt dwa złote osiemdziesiąt dziewięć      groszy ) z ustawowymi odsetkami za opóźnienie od dnia 27 kwietnia 2017  r. do dnia zapłaty;
- kwotę 123,00 zł ( sto dwadzieścia trzy złote z ustawowymi odsetkami za opóźnienie od dnia 27 kwietnia 2017  r. do dnia zapłaty;
II zasądza od pozwanego S.S.W. w C. na rzecz powoda B.C. P. Spółka z ograniczoną odpowiedzialnością  w W. kwotę 5144,00 zł ( pięć tysięcy sto czterdzieści cztery złote ) tytułem zwrotu kosztów procesu, w tym 3617,00 zł ( trzy tysiące sześćset siedemnaście złotych ) tytułem zwrotu kosztów zastępstwa procesowego.
